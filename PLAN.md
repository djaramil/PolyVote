# PolyVote — Project Plan

A Polymarket-style opinion voting app. Topics are **news headlines auto-imported from RSS
feeds** across multiple categories. The community votes **thumbs up / thumbs down** and
discusses each story in comments.

---

## 1. Concept & Scope

- **Type:** Opinion polls (sentiment voting) on **news headlines from RSS feeds**. Not a money/prediction market.
- **Source of topics:** Auto-imported from RSS feeds. Users do **not** create topics.
- **Categories (broad mix):** Politics, Technology, Sports, Business, Entertainment, Science.
- **Core loop:** Browse news by category → vote up/down → discuss in comments.
- **MVP features:**
  - Authentication (sign up / log in / log out)
  - RSS ingestion pipeline that turns articles into votable topics (server-side, scheduled)
  - Category browsing / filtering
  - Vote thumbs up / thumbs down (one vote per user per topic, changeable)
  - Comments on topics (flat list for v1)
  - Feed with basic sorting (newest, most votes) within/across categories
- **Deferred (post-MVP):** Leaderboards/trending, user profiles, threaded comments,
  user-submitted topics, prediction-market resolution & reputation scoring.

## 3. Visual Design (Modern Dark)

- **Background:** near-black (`#0B0F14`) with subtle elevated card surfaces.
- **Accents:** green (up `#22C55E`) / red (down `#EF4444`); a brand accent (e.g. violet/cyan).
- **Cards:** glassy, rounded-2xl, soft borders, hover elevation.
- **Vote bar:** horizontal up/down ratio bar that animates on vote.
- **Typography:** clean sans (Inter), strong hierarchy.

### Key screens
1. **Feed** — news cards (headline, source, image, category badge) with vote bar + counts; category tabs + sort controls.
2. **Topic detail** — full headline, summary, link to source article, big vote buttons, vote ratio, comment thread.
3. **Auth** — login / signup screens.

> Note: No "create topic" screen — topics are generated by the RSS pipeline.

## 5. Cloud Code Functions & Jobs

- `castVote(topicId, value)` — upsert the user's vote, recompute `upCount`/`downCount`.
- `addComment(topicId, body)` — create comment, increment `commentCount`.
- **`ingestFeeds` (Cloud Job, scheduled)** — fetch each enabled `Feed`, parse RSS items,
  and create `Topic` objects, skipping any whose `guid` already exists (de-dup).
  Runs server-side to avoid browser CORS issues. Scheduled every ~30 min via Back4App.
- (Triggers) keep cached counts consistent on delete.

### RSS ingestion notes
- Parse XML in Cloud Code (e.g. `rss-parser` / `fast-xml-parser`).
- Map each feed → category via the `Feed` config.
- Optionally prune Topics older than N days to keep the feed fresh.

## 6. Build Phases

1. **Setup** — Create Back4App app, scaffold Vite + React + Tailwind, install Parse SDK, wire config.
2. **RSS pipeline** — Seed `Feed` config, build `ingestFeeds` Cloud Job, verify Topics populate; schedule it.
3. **Auth** — Signup/login/logout, session persistence, protected routes.
4. **Feed UI** — List Topics as news cards, category tabs/filtering, topic detail page, sorting.
5. **Voting** — Vote buttons + Cloud Code `castVote`, animated ratio bar.
6. **Comments** — Comment list + add comment via Cloud Code.
7. **Polish** — Loading/empty/error states, responsive layout, dark-theme refinement.
8. **Deploy** — Build and host the frontend; confirm Cloud Code + scheduled job are live.
